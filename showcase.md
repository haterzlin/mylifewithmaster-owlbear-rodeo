# My Life with Master

An unofficial Owlbear Rodeo companion extension for **My Life with Master**, the independently published tabletop role-playing game by Paul Czege.

The extension helps the GM and players manage the Master, minions, relationships and game mechanics together.

## Features

- shared Master, lair and environment description;
- minion character sheets and attributes;
- shared acquaintances with individual Love values;
- Master commands;
- Violence, Villainy and Approach actions;
- Intimacy, Despair and Honesty bonus dice;
- help between minions;
- captivity, Horror manifestations and the Finale;
- live results feed synchronized between players;
- Czech and English interface;
- Owlbear Rodeo light and dark themes;
- desktop and mobile layout.

## Usage

1. Add the extension to Owlbear Rodeo using the manifest.
2. Enable it in a room.
3. The GM creates the Master and environment.
4. Players create their minions.
5. Resolve actions in the extension; results appear in the live feed for everyone.
